# ResearchProject - BICT | FOT - USJ
This website is created to showcase our group research project which is an essential for the bachelor of Information and Communication Technology (Hons) degree in Faculty of Technology, University of Sri Jayewardenepura.

# About the Project
🛡️ Enhance Network Security with AI-Powered Honeypot

This project, a BICT Honours Degree thesis, addresses the limitations of traditional security systems by integrating honeypots for passive threat intelligence gathering with Artificial Intelligence (AI) for real-time, automated defense and mitigation.

The resulting system is a closed-loop security architecture that automatically detects, classifies, and responds to cyber threats without human intervention.

🚀 Performance Highlights

The system was tested against real-world attack simulations (e.g., using Hydra).
Detection Speed: The solution can detect and respond to SSH brute-force attacks within 5 to 10 seconds.
Model Accuracy: The primary classifier, Random Forest, achieved a 100% test accuracy in distinguishing between benign, brute-force, and dictionary attacks.
Response Time: Automated response significantly reduced the time-to-containment from minutes (manual) to seconds.

💡 Academic and Practical Significance

This project serves as a cost-effective and practical solution for small organizations, universities, and research labs. It bridges the gap between passive honeypot threat intelligence and active, AI-based automated prevention, offering an open lab framework and scripts for further research and cybersecurity education.
